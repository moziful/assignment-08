# SkillSphere

## Project Purpose
SkillSphere is a learning platform built with Next.js that helps users browse courses, explore instructors, view new releases, and manage their account through simple authentication and profile pages.

## Live URL
https://assignment-08-three-snowy.vercel.app/

## Key Features
- Browse all available courses
- View popular courses and newest releases
- Read learning tips and meet top instructors
- Sign up, sign in, and manage profile information
- Smooth scroll-based animations using Framer Motion
- Responsive UI built with Tailwind CSS and DaisyUI

## NPM Packages Used
- `next`
- `react`
- `framer-motion`
- `better-auth`
- `@better-auth/mongo-adapter`
- `mongodb`
- `react-icons`
- `react-toastify`
- `tailwindcss`
- `daisyui`

## Getting Started
Run the development server:

```bash
npm run dev
```

Then open `http://localhost:3000` in your browser.
